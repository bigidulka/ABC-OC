СОСТАВ
10 отчётов Word: Linux №1–7; Windows №2, №3 и «Файловые системы» №4.
Оформление по прежнему комплекту АВС: Times New Roman 14, интервал 1,15;
A4, поля слева 2,5 см, справа 1,5 см, сверху и снизу 2 см.
Все 56 исходных встроенных изображений сохранены без изменения байтов.
Папка linux содержит четыре Bash-скрипта и пример двух записей cron.
Папка evidence содержит протоколы, учебные данные и результаты проверок.

ЗАПУСК СКРИПТОВ
bash linux/sum.sh -9 5
bash linux/archive_txt.sh Учеба /путь/к/учебному/каталогу /путь/к/архивам
При вызове archive_txt.sh с одним аргументом источником будет настоящий HOME.
В cron-example.txt каждая запись занимает одну физическую строку.
Для опыта с cron используйте учебную VM и после проверки удалите только
добавленные учебные записи, сохранив остальные задания.
